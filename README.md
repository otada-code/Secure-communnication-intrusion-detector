# Secure Communication & Intrusion Detector
Python Flask - Secure Login with Intrusion Detection for Cyber Defence

## Overview
Military-grade secure login system built to demonstrate cyber defence skills for KDF Signals.

## Features
- Encrypted password storage using bcrypt
- IP-based Intrusion Detection (blocks after 3 failed attempts)
- Real-time security logs with IP, time, status
- Secure session management

## Tech Stack
Python Flask, SQLite, bcrypt

## How to Run
pip install Flask bcrypt
python app.py
